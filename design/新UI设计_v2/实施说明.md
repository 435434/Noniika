## 1. 关于「Tailwind 类名」的取舍（必须先说清）

任务要求"使用 .md 中指定的现有组件库和 Tailwind 类名"。但设计上下文里**没有 Tailwind**：
组件库是 `cep/css/style.css` 的自有类（`.card` `.row` `.actions` `.navbtn` `.runbtn` `.chk` …），
而 .md 明文规定 **"不引入任何新的依赖"** 且面板是 CEP 离线环境（无 CDN 可用）。

→ **本稿的取舍：严格使用 .md 指定的现有类 + §4.2 的 7 个新组件类，不引 Tailwind。**
三条要求（现有组件库 / Tailwind / 无新依赖）互相冲突时，.md 自称"唯一事实来源"，故以 .md 为准。
若你确实要 Tailwind，那与"无新依赖 + CEP 离线"相矛盾，需要单独再议。
