这版重设计改了什么（对照旧版）

导航标签栏取代"返回式"二级页 —— 首页 / 人声分离 / 字幕样式 / 设置四页平铺，任何功能一击直达；⚙ 与标签双入口并存，老用户肌肉记忆不丢。
首页「开工前检查」一卡通 —— 原「素材卡 + 引擎状态条 + 两个导航按钮」三块合并成一张卡：素材 / 识别引擎 / 人声分离 / 字幕样式四行，每行带直达按钮；打开面板 3 秒知道"能不能直接点"。
层级维护动作沉底 —— 清理内存 / 清理插件文件挪到首页最底部（日志之下），低频操作不再挤占主路径。
保留上一轮已验证的好东西全保留 —— 流程步骤条、结果统计网格 + 产物 chips、字幕预览框（实时）、依赖状态网格、密钥显隐、:focus-visible、360 单列降级。
配色更深一档的工作室黑 —— 底色 #1f1f1f，让画面里的素材与彩色字幕成为最亮的东西；语义色一律"圆点 + 文字"双编码。
功能零删减：4 页 + 3 弹窗、121 个旧 id 全保留（只增不改名）、28 个持久化设置全部在位 —— 逐条对照见同目录 功能清单.md；设计取舍与实施步骤见 设计说明.md。
