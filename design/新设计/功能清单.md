## 六、全局机制（新 UI 必须兼容）

- **页面切换**：`showPage(name)` + `pgIn/pgBack` 动画（只动 opacity/translateY，不加 fill-mode —— IME 候选窗坐标问题）
- **持久化**：28 个 `persistKeys` 改动即存（见 main.js:4057）
- **联动**：`syncNoLayerWarn` / `syncStyleUi` / `syncUvrUi` / `syncAsrUi` / `updateUvrButtons` / `syncModelHint` / `syncFavFont` / `syncFavPreset`
- **平台约束**：`color-scheme: dark`；表单选择器覆盖 text/number/password/checkbox/color/range；深色滚动条；无 `<datalist>`、无 `<a>` 外链（走系统浏览器）；CEP 面板 460×720 默认 / 360×420 最小

**合计：4 页 + 3 弹窗 · 121 个现有 id · 28 个持久化设置 · 0 个可删功能。**
