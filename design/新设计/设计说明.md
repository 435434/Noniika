## 1. 设计目标 → 布局决策

| 要求 | 对应决策 |
|---|---|
| 布局清晰 | 四页信息架构保留（它经过 9 个版本迭代验证），但页内按"主路径优先"重排 |
| 操作直观 | **顶部标签栏**取代"返回式"二级页 —— 大众最熟的导航模式，任何功能一击直达 |
| 符合大众习惯 | ⚙ 在右上、主按钮最大最亮、破坏性操作最小最灰、弹窗"推荐在左/取消在最右" |
| 易于上手 | 首页第一张卡就是**「开工前检查」**：能不能直接点生成字幕，3 秒有答案 |
| 功能不遗漏 | 121 个旧 id 全保留 + 新增 33 个（只增不改名）；逐条对照 `功能清单.md` |
| 深色 | 全新"工作室黑"体系：底色 #1f1f1f，比 AE 原生更深一档 |

## 2. 三处结构性改动（其余全部保留）

### 2.1 标签栏 = 全部导航
- `首页 / 人声分离 / 字幕样式 / 设置` 四页平铺，**没有"返回"概念**（新 id：`tabs` `tabHome` `tabUvr` `tabStyle` `tabSet`）
- 旧版二级页的 `← 返回` 按钮删除 —— 标签让"迷路"不可能发生
- `⚙` 保留在右上（老用户肌肉记忆），与「设置」标签双入口并存
- 各页大标题删除（标签栏已表明位置），省出纵向空间

### 2.2 首页「开工前检查」一卡通
原首页有四块分散的状态：素材卡、引擎状态条、两个人声/样式导航按钮。合并为一张卡的四个状态行：

```
● 素材       「建军大业_片段03」· 视频+音频 · 12.4 秒
● 识别引擎   硅基流动·免费档 / SenseVoiceSmall（档位默认）· 密钥已配置   [更改]
● 人声分离   开 · Kim Vocal 2 · GPU                                    [设置]
● 字幕样式   每句一层 · 72 · 华文行楷                                   [设置]
```

- 每行 = 圆点 + 名称 + 当前值 + **直达按钮**（行按钮复用旧 id：`btnEngChange` `btnGoUvr` `btnGoStyle`，值 span 复用 `navUvr` `navStyle`）
- 异常态语义色：缺密钥 → 该行转红并写明"怎么补"；环境未装 → 置灰写"未安装"
- 解决的问题：旧版要看三处才知道"现在能不能点"

### 2.3 维护动作沉底
清理内存 / 清理插件文件从首页中部挪到**最底部**（日志之下）—— 低频操作不挤占"素材→生成"主路径。
