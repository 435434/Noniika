在同一个合成里创建字幕文本图层（可套文字动画预设）。

· 可丢弃疑似误识别段（默认只标记不删）
· 可选去掉字幕里的标点符号（数字里的 3.14、1,000 会保留）
· 输出 .srt / .json / .txt 三种产物

人声分离（本地运行）
· 11 个模型可选（人声质量优先 / 人声伴奏并重 / 速度优先三档）
· 分离目标可选：仅人声 / 仅伴奏（卡拉OK）/ 两者都要
· 输出 WAV / FLAC / MP3
· 支持 GPU 加速（NVIDIA，装 CUDA 版后快十几倍）
· 分离出的人声可自动落到时间线（替换原音频或放它下方）

字幕样式
· 每句一层（改哪句点哪句）或单层+关键帧（图层少）
· 图层名可用那句文字命名，找起来快
· 字体按名称/拼音/首字母搜索，常用字体可收藏
· 直接从时间线上已有的文本图层"拾取"字体字号颜色
· 可套 AE 自带的文字动画预设（内置搜索）

【常见问题】

Q：真的免费吗？以后会收费吗？
A：免费，功能完整，没有付费版。许可写明了不得收费转售 —— 我自己也不会做"付费解锁"。

A：① 必须重启 AE（扩展只在启动时加载）② 检查菜单路径：窗口 → 扩展 → Noniika
   ③ 安装脚本会自动打开 CEP 调试模式，若之前手动关过会加载失败。

Q：提示「缺少 API Key」？
A：面板右上角 ⚙ → 识别选项 → 选引擎 → 粘贴密钥 → 点「测试密钥」。
   测试不消耗识别额度，会立刻告诉你密钥是否可用。

Q：免费引擎真的免费吗？
A：插件本身不收费、也不代收。识别用你自己申请的账号，免费档零成本；需要实名认证，
   这一步在服务商网站完成。

Q：字幕时间跟说话对不上？
A：免费档没有时间戳，时间轴是按停顿（静音检测）重建的。句子之间有明显停顿的素材

Q：人声分离好慢？

Q：音频会上传到哪？
A：只上传到你**自己选择的**服务商。人声分离完全在本地跑。
   如果你希望完全不出网，可以用「自建 / OpenAI 兼容」档位接本地 Whisper。

Q：支持 Mac 吗？
A：暂不支持，目前只在 Windows 10/11 上验证过。

Q：更新也要钱吗？
A：不用。所有更新都免费，直接回这条动态下载最新版。

Q：发了电能退款吗？
A：发电是赠与，不是购买，正常没有"退款"概念；真误发了，留言给我，我转回去。
